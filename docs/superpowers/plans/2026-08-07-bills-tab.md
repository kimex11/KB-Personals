# Bills Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Build out the Bills tab from a placeholder into a status-grouped, searchable, filterable bill list with a functional Mark-as-Paid toggle and a Calendar view that relocates the existing month-grid calendar here.

**Architecture:** New `Bill` data model + pure selectors (status derivation, grouping, filtering, sorting, monthly total) in `lib/`, composed into presentational components under `components/bills/`, wired into `app/(shell)/bills/page.tsx` with a List/Calendar view toggle. Calendar view reuses `MonthGrid`/`DayDetailPanel` unchanged, reading the existing `useCalendarEvents()` hook.

**Tech Stack:** Next.js App Router, TypeScript, Tailwind v4, date-fns, Vitest + RTL.

## Global Constraints

- Mock data only (`lib/bills-data.ts`), following the `dayOffset` seed pattern from `mock-data.ts`/`dashboard-data.ts`.
- Currency ₱, `.toFixed(2)` line items, `.toFixed(0)` summary totals.
- New tokens `--color-status-success` (#1E8E5A) and `--color-status-warning` (#D9932B) added to `app/globals.css`, alongside existing `--color-status-critical`.
- Reuse `Button`, `EmptyState` primitives. `MonthGrid`/`DayDetailPanel` untouched, just newly referenced here instead of Home.
- TDD: failing test before implementation, every file.
- Test command: `npm test`.
